# Web Proxy Investigation Cases

Five sanitized SOC investigations covering suspicious and potentially malicious web activity observed through Web Proxy telemetry.

## Cases

1. Cryptocurrency Mining Website
2. Dark Web Access
3. Compromised Site Access
4. Suspicious Executable Download
5. Large Data Exfiltration

## Investigation Focus

- URL and domain analysis
- User and host scoping
- Web traffic analysis
- IOC identification and validation
- Threat-intelligence investigation
- Data-exfiltration analysis
- Incident response and remediation recommendations
