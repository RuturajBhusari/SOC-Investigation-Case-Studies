# SOC Investigation Case Studies

A practical SOC investigation portfolio covering security alerts and incident investigations across WAF, VPN, Web Proxy, Firewall, and IPS technologies.

## Overview

This repository documents structured security investigations from initial alert/ticket review through triage, log analysis, IOC investigation, threat-intelligence validation, event correlation, impact assessment, response actions, remediation, and final conclusions.

## Investigation Workflow

1. Alert and ticket review
2. Initial triage
3. Log and event analysis
4. Source/destination investigation
5. IOC identification
6. Threat-intelligence validation
7. Event correlation
8. Timeline reconstruction
9. Impact assessment
10. Incident classification
11. Response and containment
12. Remediation recommendations
13. Final conclusion
